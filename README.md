## Gait Analysis for Fall Risk Prediction Using OpenPose and Deep Learning

### Abstract
Falls remain a leading cause of severe injury and mortality among the elderly, underscoring the urgent need for proactive risk prediction rather than post-incident detection. To address the limitations of current reactive systems, this study proposes a computer vision-based approach that analyzes gait to predict fall risks directly from video feeds.

### Methodology
- **Feature Extraction**: The system utilizes OpenPose to extract 2D human skeleton representations.  
- **Hybrid Modeling**: These features are fed into a hybrid deep learning model combining Graph Convolutional Networks (GCN) and Reinforcement Learning (RL), enabling effective learning of both spatial joint relationships and temporal motion dynamics.

### Scope & Evaluation
The study focuses on indoor environments using fixed RGB cameras. Experiments are conducted on standard datasets (UR-Fall and UP-Fall), simulating elderly individuals or those with impaired balance. Model performance is evaluated using Accuracy, F1-score, and AUC metrics.

### Conclusion
The results demonstrate the strong potential of the proposed method as an automated early-warning system for hospitals, nursing homes, and smart home environments, contributing to improved safety and healthcare quality for the elderly.
